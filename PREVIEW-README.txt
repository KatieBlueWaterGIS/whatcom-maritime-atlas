LOCAL PREVIEW - WINDOWS

1. Extract this ZIP to a normal folder.
2. Double-click preview.bat.
3. A browser window should open automatically at http://localhost:8000/
4. Use the site normally:
   - Hub: http://localhost:8000/
   - Tides: http://localhost:8000/tides.html
   - Mapped Memories: http://localhost:8000/mapped.html
5. Leave the black PowerShell/Command Prompt window open while previewing.
6. Press Ctrl+C in that window when finished.

This uses Windows PowerShell/.NET only. Python and Node are not required.
